# Ничто, ведущее к файлу, не пересекает сокет

Виджет показывает четыре вещи, которых нет в hook payload: собственное имя сессии, имя проекта,
ветку git и размер контекста. Их разрешает hook-процесс — только он держит сырые `session_id`,
`transcript_path` и `cwd`, — и через сокет идут одни готовые значения; от рабочего каталога уходит
его собственное имя, а не путь к нему. Обещание проверяется на границе приёма, а не только
намерением отправителя: значение с разделителем пути отбрасывается на входе.

**Следствие, которое иначе выглядит дублированием.** Приложение не может открыть файл, о котором
ему не сказали, поэтому транскрипт оно находит само — через `TranscriptLocator`, по имени каталога.
К одному файлу ведут два разных пути, и это цена правила, а не недосмотр.

Подробности и остальные ограничения — `docs/architecture.md` §15.
