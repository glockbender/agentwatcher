# Контекст Claude читается из транскрипта

**Статус:** принято 2026-11-25.

Agent Watch убирает интеграцию со статус-строкой Claude. Виджет показывает число токенов,
отправленных модели при последнем запросе основного разговора. Приложение читает его из
транскрипта при обычном наблюдении за сессией. Лимиты подписки для папки по умолчанию приходят
из снапшота Claude Code и запроса `get_usage` по [ADR-0026](0026-claude-limits-come-from-its-own-snapshot.md).
Для дополнительных папок Claude на странице `Usage profiles` квоты отсутствуют.

## Почему

Чтобы подключить интеграцию, человек отдавал Agent Watch единственный слот статус-строки.
Приложение оборачивало его команду своим скриптом и запускало ещё один процесс при каждом
обновлении. Так мало кто подключал интеграцию. Число токенов уже доступно в записи ответа,
которую приложение читает для наблюдения.

## Что показал замер

В четырёх новых сессиях `claude -p` с коротким ответом в `message.usage` были три входных
счётчика: `input_tokens`, `cache_read_input_tokens`, `cache_creation_input_tokens`. Их сумма
даёт вход последнего запроса, включая кэш (замер: Claude Code 2.1.326).

- Sonnet 4.6 с `[1m]` и без него записал один `message.model`. Суффикс сохранился в
  `requestedModel`, а в запросе с суффиксом был заголовок `context-1m-2025-08-07`.
  Поле `modelUsage.<модель>.contextWindow` в результате команды показало 1 000 000 и 200 000
  соответственно (замер: Claude Code 2.1.326).
- Два запуска Opus 5.5, обычный и с `CLAUDE_CODE_DISABLE_1M_CONTEXT=1`, вернули те же два
  размера. У них совпали `requestedModel`, `message.model`, список `params.betas` и
  `params.max_tokens` в транскрипте. В самом транскрипте размер окна не записан
  (замер: Claude Code 2.1.326).

Поэтому идентификатор модели и суффикс не дают общего правила для вычисления процента.
`modelUsage` приходит в результате `claude -p`; Agent Watch наблюдает и сессии, запущенные
другими способами. Решение о выводе числа токенов согласовано с владельцем.

При восстановлении строки после перезапуска приложение сохраняет счётчик без процента до
следующего чтения. Сохранённые показания обёртки с процентом отбрасываются: её счётчик
суммировал входные токены по сессии.

## Что происходит со старой настройкой

Приложение оставляет настройки Claude как есть. Отправитель завершает вызов с удалённым
именем события до чтения stdin. Старая обёртка продолжает передавать данные команде
пользователя и сохраняет её вывод. Порядок восстановления команды в Claude описан в
[руководстве](../../TROUBLESHOOTING.md#claude-still-runs-the-agent-watch-status-line-relay).
