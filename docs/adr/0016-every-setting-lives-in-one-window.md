# Все настройки — в одном окне

У меню строки состояния нет настроек. В нём сводка (заголовок раздела), строки сессий (один
прокручиваемый список, [ADR-0018](0018-the-menus-sessions-are-one-scrolling-list.md)), `Show Widget` только пока виджет скрыт,
`Settings…` (⌘,) и `Quit`. Отдельного пункта, чтобы найти виджет, нет: показ виджета сам его
подсвечивает. Всё остальное — в окне настроек, включая Tooling и журнал событий (`Diagnostics`) и
запись сырых хук-пейлоадов отладочной сборки.

Окно — SwiftUI: боковая панель, как в System Settings, в каждой странице — сгруппированная форма.
Страницы перечислены в [architecture.md](../architecture.md) §8, «Окно настроек виджета». Сторы
остаются единственным источником правды: контрол пишет в стор, окно читает обратно.

## Почему

Владелец назвал прежнее окно и меню неудобными: стрелки ↑↓ перестраивали всю сетку под указателем,
контролы появлялись и исчезали в зависимости от выбора, а половина настроек пряталась в
подменю, где её не найти. Правила окна:

- **Порядок меняется перетаскиванием.** Части строки и блоки порядка — список с ручкой, без
  стрелок.
- **Ничего не перестраивается от переключателя.** Выключенная часть остаётся на своём месте в
  списке; неприменимый контрол серый, но не исчезает, и рядом сказано почему.
- **Одно место для настроек.** Меню — для того, что делают во время работы.

## Чем за это платим

Выбор значка нельзя сделать, не открывая окно. Подменю с переключателями из
[ADR-0014](0014-a-menu-choice-of-several-is-lines-that-draw-themselves.md) ушли; его приём —
строка меню, которая рисует себя сама, — нужен теперь только строке сломанной сессии: клик по ней
должен оставить меню открытым для вопроса, завершить ли агента
([ADR-0013](0013-a-click-ends-an-agent-its-closed-terminal-left-behind.md), «Клик спрашивает»).

Стекло (Liquid Glass) приходит само: при сборке с SDK macOS 26 боковая панель `NavigationSplitView`
становится стеклянной, формы лежат на обычном фоне окна, как в System Settings. На macOS 14–25 та же
панель рисуется системным материалом сайдбара. Стекло самого виджета — решение темы,
[ADR-0017](0017-a-theme-owns-every-colour.md), «Стекло».
