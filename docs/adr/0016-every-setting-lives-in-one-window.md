# Все настройки — в одном окне

С 2026-09-29 у меню строки состояния нет настроек. В нём остались сводка (заголовок раздела),
строки сессий (не больше восьми, остальное — одной строкой «N more in the widget»), `Show Widget`
только пока виджет скрыт, `Settings…` (⌘,) и `Quit`. `Highlight Widget` убран: показ виджета сам
его подсвечивает. Tooling и Event Debug — панели окна настроек (`Tooling`, `Diagnostics`), туда же
ушла запись сырых хук-пейлоадов отладочной сборки. Всё, что раньше
жило в подменю `Settings` (значок, сессии в меню, поведение виджета, закрытые сессии, чтение
транскриптов, обновления), переехало в окно настроек.

Окно — SwiftUI: боковая панель, как в System Settings (Row, Order, Lamp, Appearance, Menu Bar,
Behavior, Tooling, Diagnostics, Updates), в каждой — сгруппированная форма. Сторы остаются единственным источником
правды: контрол пишет в стор, окно читает обратно.

## Почему

Владелец назвал прежнее окно и меню неудобными: стрелки ↑↓ перестраивали всю сетку под указателем,
контролы появлялись и исчезали в зависимости от выбора, а половина настроек пряталась в
подменю, где её не найти. Правила нового окна:

- **Порядок меняется перетаскиванием.** Части строки и блоки порядка — список с ручкой, без
  стрелок.
- **Ничего не перестраивается от переключателя.** Выключенная часть остаётся на своём месте в
  списке; неприменимый контрол серый, но не исчезает.
- **Одно место для настроек.** Меню — для того, что делают во время работы.

## Чем за это платим

ADR-0014 (строки меню, которые рисуют себя сами) больше не нужен: подменю с переключателями
ушли, и `MenuToggleRowView` удалён. Выбор значка теперь нельзя сделать, не открывая окно.

Стекло (Liquid Glass) приходит само: при сборке с SDK macOS 26 боковая панель `NavigationSplitView`
становится стеклянной, формы лежат на обычном фоне окна, как в System Settings. На macOS 14–25 та же
панель рисуется системным материалом сайдбара.

## Одна строка, которая рисует себя сама

Дополнено 2026-09-30. Строки со своим видом из меню ушли, а одна вернулась: строка сломанной
сессии. Клик по ней должен оставить меню открытым для вопроса, завершить ли агента, а обычная
строка меню от клика закрывается. Почему так и чем за это платим — в
[ADR-0013](0013-a-click-ends-an-agent-its-closed-terminal-left-behind.md), «Клик спрашивает».
