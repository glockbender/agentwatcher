# Защита Git использует общие настройки профилей агента

**Статус:** принято 2026-11-26.

[ADR-0025](0025-a-branch-type-chooses-the-check-above-a-floor.md) задаёт нижнюю границу проверки
защищённых веток. В интерфейсе одна строка меняла два разных действия, а правило репозитория
настраивалось в другом месте. При временном выключении приходилось удалять обработчики и затем
восстанавливать доверие Codex.

Приложение хранит общий переключатель и отдельные правила принудительной отправки и удаления.
При выключении установленный обработчик пропускает команды со следующего вызова. Регистрации
и доверие в профилях сохраняются. При включённой защите ветки из ADR-0025 сохраняют нижнюю
границу. Прямой вызов исполнителя сохраняет проверку, даже если обработчик выключен.

Переключатель и правила записываются атомарно в один файл. Если он недоступен, действуют
встроенные проверки. Вариант с отдельным переключателем в каждом профиле потребовал бы
согласования нескольких файлов. Удаление регистрации при выключении потребовало бы заново
подтверждать доверие при включении. Единый пользовательский файл также читается при закрытом
приложении. Он доступен тому же пользователю, от которого работают агенты, поэтому переключатель
защищает от случайного выключения в интерфейсе, а не от намеренной правки файла.

Правило репозитория может поднять уровень, выбранный первым совпавшим общим правилом. Ключ —
канонический путь общей папки Git. Связанные рабочие копии получают те же правила. Перенос
репозитория меняет его ключ, а копия с тем же сервером получает собственный набор правил.
