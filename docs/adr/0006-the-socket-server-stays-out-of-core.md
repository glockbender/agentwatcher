# Приём по сокету живёт вне `AgentWatchCore`

**Статус:** принято 2026-09-15.

`AgentWatchIngress` — это один файл, и соблазн свести его в Core будет возникать у каждого
следующего ревью. Отклонено: слушающий сокет внутри таргета детерминированного состояния ослабляет
ровно то свойство, ради которого Core и существует, — состояние проверяется тестами, которым не
нужны ни машина, ни права, ни порт.

Отдельный таргет — это и есть запись правила: чтобы нарушить его, придётся поменять `Package.swift`.
